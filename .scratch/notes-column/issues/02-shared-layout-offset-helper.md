# 02: Префакторинг — общий хелпер отступа контента от ширины сайдбара

**What to build:** Все четыре места с захардкоженным отступом контента от ширины сайдбара (область контента, нижняя панель записи, оверлеи статуса, панель «Найти и заменить») вычисляют отступ через один общий хелпер вместо собственных литералов `4rem`/`16rem`. Поведение не меняется — хелпер возвращает прежние значения. Это подготовка к тикету 03, где отступ должен будет дополнительно учитывать ширину колонки заметок.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Существует общий хелпер вычисления отступа контента от состояния сайдбара (свёрнут/развёрнут); все четыре потребителя используют его вместо собственных литералов
- [x] Визуально отступы не изменились ни при свёрнутом, ни при развёрнутом сайдбаре
- [x] Unit-тест хелпера покрывает оба состояния сайдбара
- [x] Все существующие тесты проходят

## Comments

Реализация (коммит `e83f8ca`, мердж `7bb1a2f`):

- **Хелпер** `contentOffset(sidebarCollapsed: boolean): '4rem' | '16rem'` — чистая функция в `frontend/src/lib/layout-offset.ts` (по прецеденту `meeting-datetime.ts`/`meeting-details-preferences.ts`). Потребители сами достают `isCollapsed` из `useSidebar()`/пропсов. Хук не выбран: чистая функция проще тестируется, все четыре потребителя уже имеют состояние сайдбара. В тикете 03 сигнатура расширена вторым параметром (ширина колонки), в тикете 03 же добавлен `sidebarWidthPx` (64/256 = w-16/w-64).
- **Потребители** (все 4): `MainContent` (классы `ml-16`/`ml-64` → inline-style `marginLeft`; дефолтный spacing Tailwind: `ml-16`≡`4rem`, `ml-64`≡`16rem`, `transition-all` покрывает margin — визуально идентично), `app/page.tsx` (RecordingControls), `StatusOverlays`, `FindReplacePanel` (значение применяется как **`marginRight`** — направление осталось за потребителем, хелпер отдаёт значение).
- **Тесты**: новый unit-тест `tests/lib/layout-offset.test.ts` по TDD (красный на отсутствующем модуле → зелёный), оба состояния сайдбара. Затронутые сьюты (recording-controls-stop 8, native-progress-render 9, find-replace-summary-navigation 6, find-replace-summary-replace-wiring 4, mode-exclusivity 8) зелёные; полный пофайловый цикл — только 3 pre-existing FAIL; `tsc` — 1 pre-existing TS7053. Grep: литералы `'4rem'/'16rem'` и классы `ml-16/ml-64` в `src/` остались только внутри хелпера.
- **Не проверялось**: GUI-прогон в Tauri; эквивалентность значений обеспечена возвратом прежних литералов.
