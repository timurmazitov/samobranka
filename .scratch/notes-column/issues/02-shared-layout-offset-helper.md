# 02: Префакторинг — общий хелпер отступа контента от ширины сайдбара

**What to build:** Все четыре места с захардкоженным отступом контента от ширины сайдбара (область контента, нижняя панель записи, оверлеи статуса, панель «Найти и заменить») вычисляют отступ через один общий хелпер вместо собственных литералов `4rem`/`16rem`. Поведение не меняется — хелпер возвращает прежние значения. Это подготовка к тикету 03, где отступ должен будет дополнительно учитывать ширину колонки заметок.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Существует общий хелпер вычисления отступа контента от состояния сайдбара (свёрнут/развёрнут); все четыре потребителя используют его вместо собственных литералов
- [ ] Визуально отступы не изменились ни при свёрнутом, ни при развёрнутом сайдбаре
- [ ] Unit-тест хелпера покрывает оба состояния сайдбара
- [ ] Все существующие тесты проходят
