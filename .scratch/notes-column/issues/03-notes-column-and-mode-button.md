# 03: Колонка заметок — список переезжает в постоянную колонку, кнопка «Заметки» становится режимом

**What to build:** Между сайдбаром и областью контента на всех страницах появляется постоянная колонка заметок фиксированной ширины: сверху строка поиска, ниже список встреч (компонент из тикета 01), при пустом списке — заглушка «Нет заметок» (en/ru). Колонку нельзя скрыть: средств закрытия нет. Из сайдбара список и поиск убраны; в развёрнутом состоянии добавлена nav-строка «Заметки» по образцу «Домой». Кнопка NotebookPen в свёрнутой панели и строка в развёрнутой — переключатель режима отображения: нажатие с главной или из настроек открывает самую свежую встречу (по прежней логике маршрутизации списка), на странице встречи — no-op, во время записи навигации нет; кнопка подсвечена на страницах заметок (главная, страница встречи) и не подсвечена на настройках. Отступы контента и нижних панелей учитывают ширину колонки через хелпер из тикета 02. Состояние активного режима колонки заделано под будущие режимы (единственное значение — заметки), UI переключения режимов нет. Запуск приложения — главная, без автоперехода к последней встрече.

**Blocked by:** 01 (extract meeting list component), 02 (shared layout offset helper)
