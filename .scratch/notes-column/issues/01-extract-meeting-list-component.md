# 01: Префакторинг — выделить список встреч из сайдбара в отдельный компонент

**What to build:** Поведение без изменений: список встреч вместе со строкой поиска, hover-действиями (удаление/редактирование, popup с числом спикеров), модалками удаления/редактирования и подсветкой активной строки вынесен из сайдбара в самостоятельный компонент, который сайдбар рендерит на прежнем месте в развёрнутом состоянии.
