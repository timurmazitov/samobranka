# 01: Префакторинг — выделить список встреч из сайдбара в отдельный компонент

**What to build:** Поведение без изменений: список встреч вместе со строкой поиска, hover-действиями (удаление/редактирование, popup с числом спикеров), модалками удаления/редактирования и подсветкой активной строки вынесен из сайдбара в самостоятельный компонент, который сайдбар рендерит на прежнем месте в развёрнутом состоянии. Это подготовка к переносу списка в колонку заметок (тикет 03): снимается главный риск спеки — перенос списка вместе со всеми его обработчиками.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Список встреч, строка поиска, hover-действия и модалки удаления/редактирования живут в отдельном компоненте; сайдбар рендерит его на прежнем месте
- [ ] Поведение не изменилось: поиск по названиям и транскриптам со сниппетами и индикатором поиска, клик по встрече с прежней маршрутизацией, удаление, переименование (название + дата), popup с числом спикеров, подсветка активной строки
- [ ] Внешний вид свёрнутого и развёрнутого сайдбара не изменился
- [ ] Все существующие тесты проходят без изменения проверяемого поведения
