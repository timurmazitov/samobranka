# 02: Режим выделения с массовым удалением

**What to build:** В группе кнопок панели транскрипта появляется кнопка «Выделение». По нажатию у строк транскрипта появляются чекбоксы, пользователь отмечает несколько речевых сегментов и удаляет их за один раз кнопкой «Удалить (N)» с подтверждением «Удалить N сегментов?» для N>1 (одиночное удаление, из 01, подтверждения не требует). Удаление идёт одной батч-командой (одна транзакция), после массового удаления текущая страница перезагружается, чтобы offset-пагинация не пропустила строки. Выделение эфемерное: сбрасывается при выходе из режима и при смене встречи, не переживает перезапуск.

**Blocked by:** 01 (Одиночное удаление речевого сегмента — даёт батч-команду, метод хука и гейты).

**Status:** claimed

- [ ] Кнопка «Выделение» в панели транскрипта включает/выключает режим; в режиме у строк отображаются чекбоксы.
- [ ] Панель действий режима: «Удалить (N)» со счётчиком выбранных; подтверждение «Удалить N сегментов?» только при N>1.
- [ ] Массовое удаление выполняется одной батч-командой; при ошибке — откат всех выбранных сегментов.
- [ ] После массового удаления — refetch текущей страницы; `totalCount`/`has_more` остаются честными, следующая страница не пропускает строки.
- [ ] Выделение не переживает выход из режима и смену встречи; не персистится между перезапусками.
- [ ] Гейты режима совпадают с гейтами одиночного удаления (запись/диаризация/ретранскрипция блокируют).
- [ ] Тесты: поведение выделения (выбор, счётчик), подтверждение при N>1 и его отсутствие при N=1, откат при ошибке батч-команды, изоляция выделения при смене встречи.
