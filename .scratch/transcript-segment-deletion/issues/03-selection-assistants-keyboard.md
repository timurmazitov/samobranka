# 03: Помощники выделения и управление с клавиатуры

**What to build:** В режиме выделения (тикет 02) пользователь может быстро отмечать сегменты массово: кнопка «Выделить всё видимое» отмечает все загруженные строки; выделение по спикеру отмечает все сегменты выбранного спикера (по метке диаризации, доступной из панели спикеров); клик по строкам с Ctrl/Shift работает как в файловом менеджере — точечное добавление и диапазоны. Delete удаляет выбранное (с тем же подтверждением при N>1), Esc выходит из режима выделения.

**Blocked by:** 02 (Режим выделения с массовым удалением).

**Status:** claimed

- [ ] «Выделить всё видимое» отмечает все загруженные на текущий момент сегменты; повторное нажатие снимает выделение.
- [ ] Выделение по спикеру отмечает все сегменты выбранного спикера; учитывает, что сегменты подгружаются постранично (выделение применяется к загруженным).
- [ ] Ctrl/Shift-клик по строкам: добавление/снятие одиночной строки и выделение диапазона от последней выбранной.
