# 03: Помощники выделения и управление с клавиатуры

**What to build:** В режиме выделения (тикет 02) пользователь может быстро отмечать сегменты массово: кнопка «Выделить всё видимое» отмечает все загруженные строки; выделение по спикеру отмечает все сегменты выбранного спикера (по метке диаризации, доступной из панели спикеров); клик по строкам с Ctrl/Shift работает как в файловом менеджере — точечное добавление и диапазоны. Delete удаляет выбранное (с тем же подтверждением при N>1), Esc выходит из режима выделения.

**Blocked by:** 02 (Режим выделения с массовым удалением).

## Comments

Реализация (тикеты 03):

- **Хук выделения** (`useTranscriptSelection.ts`): три новых метода поверх существующего набора id — `selectAllVisible(ids)` (замена с сохранением порядка выбора уже отмеченных строк: Shift-якорь остаётся последним реально тронутым id), `toggleAllVisible(ids)` (кнопка-переключатель: всё видимое уже отмечено → сброс, иначе — дозаполнить), `rangeSelectTo(targetId, orderedIds)` (файловый менеджер: диапазон от **последнего выбранного** id до цели по порядку загруженного окна, включительно, в обе стороны; без якоря — одиночное выделение; если якорь или цель выпали из окна — одиночный toggle).
- **Кнопки помощников** — в панели действий `VirtualizedTranscriptView` (рядом с «Удалить (N)», за общими гейтами режима): «Выделить всё видимое» (lucide `ListChecks`) и дропдаун «Спикер» (lucide `Users`, список из `meetingSpeakers` — данные панели спикеров, порядок чипов `orderMeetingSpeakersForChip`). Обе существуют только при хозяине-колбэке (живая страница не получает) и при непустом списке спикеров.
- **Провязка страницы** (`page-content.tsx`): «всё видимое» = `segments.map(id)` хука пагинации (загруженное окно, не `totalCount`); «по спикеру» — фильтр загруженных сегментов по `segment.speaker === label` (никогда `meetingSpeakers[].segment_count` — это вся встреча, счётчик «Удалить (N)» соврал бы); Shift-клик хостит `rangeSelectTo` с порядком загруженного окна (порядок = audio_start_time из репозитория).
- **Ctrl/Shift-клик по строке**: обработчик висит на `<p>` текста и появляется только при `canSelect && onRowRangeSelect` — обычные клики не перехватываются (текст остаётся выделяемым). Ctrl (и Cmd) → тот же `onToggleSelected`, что и чекбокс; Shift → хост-диапазон. `preventDefault` на модифицированных кликах гасит pull text-selection. Проброшен в **обе** ветви рендера (виртуализированную и маленький список).
- **Delete/Esc — расширение ЕДИНСТВЕННОго document-слушателя страницы** (паттерн тикета 02 из хэндоффа): Escape при активном режиме вызывает `preventDefault()` (перебивает closePanel find-панели, слушатель которой уважает `defaultPrevented`) и `exitSelection()` (сбрасывает режим и id). Delete (и Backspace — Mac-клавиши) при выбранном инкрементит `bulkDeleteNonce` — страницу-владелец не дублирует подтверждение: вью по смене nonce нажимает **тот же** `handleBulkDeletePress`, что и кнопка (подтверждение N>1, тосты из переводных строк — общий путь, разойтись не может; прецедент nonce — `focusNonce` find-панели). Клавиша не срабатывает вне режима, при пустом выборе и когда фокус в текстовом поле (`isTypingTarget`: INPUT не-чекбокс/TEXTAREA/SELECT/contentEditable) — Delete не съедает набор текста в редакторе строки и полях find.
- **Каталоги**: ключи `transcript.selectAllVisible/selectAllVisibleTooltip/selectBySpeaker/selectBySpeakerTooltip` в en+ru («речевые сегменты», без «реплика»); i18n-parity и i18n-usage зелёные.
- **Тесты** (bun, пофайлово): `transcript-selection` 12 (всё видимое, повторное нажатие, частичное дозаполнение, диапазоны в обе стороны, range без якоря), `transcript-selection-assistants` 15 (кнопки в панели + гейты + отсутствие у живой страницы, дропдаун спикеров, модификатор-клики, nonce-путь Delete с подтверждением N>1 и инертность при том же nonce), `meeting-details-selection-assistants` 9 (страничный seam: всё видимое = загруженные id, по спикеру = фильтр loaded, shift-range через панель, Esc-приватизация перед find-панелью, Delete-nonce, гейт «фокус в текстовом поле», Ctrl+F не сломан). Прогнаны заново: paginated-transcripts 25, transcript-selection-mode 11, transcript-selection-button 4, transcript-row-delete 7, meeting-details-summary-hint 13, i18n-parity 5, i18n-usage 11, find-replace 37, плюс transcript-text-edit 17, diarization-speaker-labels 22, find-replace-summary-* 8, meeting-details-refresh 3 — все зелёные. `tsc --noEmit` чисто, кроме документированной `stage-transcribe-native.test.ts`. Полный `bun test` в этом окружении остаётся загрязнённым cross-file `mock.module` (123 fail на чистом cab07ad; методика — пофайловые прогоны, docs/RUNNING_LINUX.md §9); проверено, что новые файлы не добавляют падений **чужим** сюитам (диф полного прогона против baseline пуст вне собственных страницей-сюит, которые падают как и соседняя `meeting-details-summary-hint`).

Заметки для 04/05: вход в режим по-прежнему через `toggleSelection`/`enterSelection`; Esc-обработчик режима живёт в ветке `event.key === 'Escape' && !event.defaultPrevented` до `closePanel()` — при интеграции взаимоисключения не переносить `preventDefault` ниже. `bulkDeleteNonce` — единственный канал клавиатурного удаления; если тикет 04 станет закрывать режим по pencil/Find, чистка id идёт через `exitSelection`, nonce трогать не нужно (он авто-игнорится при `!canBulkDelete`).
