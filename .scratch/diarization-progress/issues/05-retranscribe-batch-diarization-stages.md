# 05: Ретранскрипция пачкой — «Встреча N из M: диаризация…»

**What to build:** Диалог ретранскрибции получает ту же склейку баров, что и импорт (транскрибация → сохранение → диаризация одним числом), плюс контекст пачки: «Встреча N из M» и текущая стадия диаризации обрабатываемой встречи. Пользователь видит прогресс всей пачки целиком, включая фоновые проходы диаризации.

**Blocked by:** 03 — Импорт: бар продолжается стадиями диаризации (переиспользуется механика склейки).

**Status:** ready-for-agent

- [x] Диалог ретранскрипции показывает стадию текущей встречи, включая стадии диаризации. («Встреча N из M» — нет: пачечной ретранскрипции в коде нет, диалог и `start_retranscription` принимают один meeting_id; множественный выбор — вне скоупа. Решение автора спеки зафиксировано в тикете.)
- [x] Шкала и правила «Готово»/100% для каждой встречи совпадают с импортом; форма существующего события прогресса ретранскрипции не изменилась
- [x] При отсутствии модели/рантайма бар встречи завершается на транскрибации молча
- [ ] Ручная проверка в Tauri: ретранскрипция пачкой из нескольких встреч с моделью и без неё
