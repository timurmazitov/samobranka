# 03: Импорт — бар продолжается стадиями диаризации до 100%

**What to build:** При импорте аудио прогресс-бар больше не «заканчивается» на транскрибации: после неё бар продолжается стадиями диаризации и доходит до 100% только когда спикеры определены. Кнопка «Готово» появляется после терминального события диаризации — либо сразу после транскрибации, если диаризация не запускалась (нет модели или рантайма). Пользователь может закрыть диалог в любой момент: detached-проход продолжается, панель Speakers подхватывает состояние.

**Blocked by:** 02 — Трейсер: событие `diarization-progress` и общий стейт прохода.

**Status:** ready-for-agent

- [ ] Шкала бара импорта: транскрибация 30–70, сохранение 70–75, диаризация 75–100 одним числом; форма существующего события прогресса импорта не изменилась
- [ ] «Готово»/100% только после терминала диаризации; при отсутствии модели/рантайма бар завершается сразу на транскрибации без сообщений об ошибке
- [ ] Закрытие диалога во время диаризации не прерывает проход; после закрытия прогресс виден в панели Speakers встречи
- [ ] Юнит-тесты чистого маппера «фаза прохода → событие прогресса» (стадия, message, наличие/отсутствие процента) и тесты молчания при `no_model`/`no_runtime`/`deferred`
- [ ] Ручная проверка в Tauri: импорт с установленной моделью и без неё
