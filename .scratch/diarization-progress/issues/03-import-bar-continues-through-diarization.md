# 03: Импорт — бар продолжается стадиями диаризации до 100%

**What to build:** При импорте аудио прогресс-бар больше не «заканчивается» на транскрибации: после неё бар продолжается стадиями диаризации и доходит до 100% только когда спикеры определены. Кнопка «Готово» появляется после терминального события диаризации — либо сразу после транскрибации, если диаризация не запускалась (нет модели или рантайма). Пользователь может закрыть диалог в любой момент: detached-проход продолжается, панель Speakers подхватывает состояние.

**Blocked by:** 02 — Трейсер: событие `diarization-progress` и общий стейт прохода.

**Status:** ready-for-human

- [x] Шкала бара импорта: транскрибация 30–70, сохранение 70–75, диаризация 75–100 одним числом; форма существующего события прогресса импорта не изменилась
- [x] «Готово»/100% только после терминала диаризации; при отсутствии модели/рантайма бар завершается сразу на транскрибации без сообщений об ошибке
- [x] Закрытие диалога во время диаризации не прерывает проход; после закрытия прогресс виден в панели Speakers встречи
- [x] Юнит-тесты чистого маппера «фаза прохода → событие прогресса» (стадия, message, наличие/отсутствие процента) и тесты молчания при `no_model`/`no_runtime`/`deferred`
- [ ] Ручная проверка в Tauri: импорт с установленной моделью и без неё

Заметка имплементации (тик. 03): последние 75..100 шкалы `import-progress` не
эмитятся нативно вовсе (веха `complete` теперь 75) — их заполняет фронт одним
числом из общего стейта прохода (`DiarizationPassStore`, тик. 02); форма
события не менялась. «Готово» держится до терминала прохода; при
`no_model`/`no_runtime` (фронт проверяет модель/рантайм/запись теми же
командами, что и панель Speakers — seam `diarizationAvailability.ts`) бар
завершается сразу на транскрибации молча. Терминалы, увиденные стором до того,
как диалог узнал meeting_id, запоминаются (`hasSeenTerminal`), иначе бы бар
висел на завершившемся проходе. Маппер фаз и тесты молчания из тик. 02 не
дублировались — добавлен только пин шкалы (`transcription_progress`, вехи
70/75). Ручная проверка в Tauri не выполнялась (GUI не запускался).
