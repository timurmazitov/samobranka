## Чек-лист ручного прогона (выполняет пользователь, `pnpm run tauri:dev` из `frontend/`)

Подготовка: модель диаризации Nemotron скачана (для сценариев «с моделью»); для сценариев «без модели» — удалена в настройках.

1. **Импорт с моделью**: бар после транскрибации продолжается стадиями диаризации (75→99, монотонно), «Готово» только после появления спикеров; закрытие диалога во время диаризации — проход продолжается, панель Speakers встречи показывает стадии.
2. **Импорт без модели**: бар завершается на транскрибации (сразу 100/«Готово»), без ошибок и тостов.
3. **Ретранскрипция** (одна встреча): та же склейка, что импорт; без модели — молчаливое завершение на транскрибации; отмена на фазе транскрибации живая.
4. **Live-stop с моделью**: после сохранения — оверлей «Определяем спикеров…», завершение после терминала; без модели — остановка завершается как раньше, без задержки; уход на экран встречи — индикатор живёт в панели Speakers.
5. **Ручной запуск из Speakers**: стадии со спиннером, кнопка disabled на время прохода (в т.ч. при авто-проходе), «Ожидание очереди» при занятом локе.
6. **Очередь**: импорт двух встреч подряд — вторая показывает «Ожидание очереди», затем свои стадии.
7. **Сбой**: повреждённое аудио → в панели «Диаризация не удалась: <причина>» + «Повторить» (повтор работает), тост сохраняется; путь к файлу в причине не виден.
8. **Нет модели/рантайма в панели**: явные подсказки (скачать модель / объяснить недоступность), приоритет модели над рантаймом.

Наблюдения, отклонения от ожиданий и дата прогона — в `## Comments` этого файла.
