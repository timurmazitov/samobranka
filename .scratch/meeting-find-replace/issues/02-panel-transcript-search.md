# 02: Панель поиска + навигация по транскрипту

**What to build:** На странице встречи пользователь нажимает `Ctrl+F` (или `Ctrl+H` — фокус сразу в поле «Заменить», которое пока без действия) либо кнопку-лупу в шапке панели транскрипта — в правом верхнем углу открывается плавающая карточка «Найти и заменить»: поля «Искать»/«Заменить», переключатели «Учитывать регистр» и «Слово целиком», счётчик «текущее / всего», кнопки ↑/↓, крестик. Нативный поиск webview при этом не открывается (клавиша перехватывается с `preventDefault`). Ввод запроса подсвечивает все совпадения во всех речевых сегментах встречи; при открытой панели сегменты показываются без очистки от слов-паразитов, чтобы позиции подсветки были честными; закрытие панели возвращает обычный вид. Навигация ↑/↓ (и Enter / Shift+Enter) проходит по общему списку совпадений с автоскроллом, включая виртуализированный список сегментов; при первом открытии панели догружаются все страницы сегментов. Нет совпадений — счётчик «0 / 0» и красная подсветка поля. Все подписи — через i18n.
