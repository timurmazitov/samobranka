# 01: Утилита поиска совпадений (префакторинг)

**What to build:** Чистая функция поиска совпадений, которой будут пользоваться все остальные билеты: по тексту и запросу возвращает упорядоченные диапазоны `[from, to)` совпадений. Режимы: подстрока без учёта регистра (по умолчанию), «учитывать регистр», «слово целиком» с корректными Unicode-границами слова (кириллица и латиница; обычный `\b` для кириллицы не подходит). Пустой/пробельный запрос — пустой список. Пересекающиеся и соседние вхождения не дублируются. Это префакторинг: поведение для пользователя ещё не меняется, но готовый протестированный кирпич нужен всем вертикальным срезам дальше.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent
