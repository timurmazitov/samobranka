# 03: Замена в транскрипте

**What to build:** В открытой панели поиска пользователь вводит текст в поле «Заменить» и нажимает «Заменить» — текущее совпадение в речевом сегменте заменяется и фокус переходит к следующему совпадению (как в редакторах). «Заменить все (N)» заменяет все совпадения во всех сегментах транскрипта за одно действие, с числом в подписи кнопки, без подтверждения. Правки проходят через существующий путь редактирования текста сегмента (оптимистичное обновление и откат при ошибке уже есть), сохраняются в базе и не теряются после перезагрузки встречи; привычный хинт «саммари устарело — перегенерировать?» продолжает работать после замен.

**Blocked by:** 02 (Панель поиска + навигация по транскрипту).

**Status:** ready-for-agent

- [ ] «Заменить» меняет активное совпадение в сегменте и переходит к следующему
- [ ] «Заменить все» меняет все совпадения во всех сегментах встречи, включая недозагруженные (после догрузки из 02)
- [ ] Заменённый текст сохраняется в БД: после перезагрузки встречи правки на месте (проверка через существующую команду обновления текста сегмента)
- [ ] Формат отображения сегмента (спикер, таймкод, чистка от слов-паразитов после закрытия панели) не ломается
- [ ] Хинт об устаревшем саммари появляется после замен
- [ ] Тесты поведения хука: вызовы команды обновления сегмента с правильным текстом для одиночной замены и «заменить все»; частичный сбой не оставляет рассинхрон состояния (откат существующий)
- [ ] Проверено вручную в `tauri:dev`
