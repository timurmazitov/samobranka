# 03: Гейт диаризации для правки текста

Type: task

**What to build:** Пока для встречи выполняется прогон диаризации, правка текста реплик недоступна: карандаш на строках не появляется, войти в редактор нельзя (в том же ключе, в каком во время прогона заблокированы действия в панели спикеров). Если же пользователь уже редактирует строку, а прогон диаризации стартовал (например, из панели спикеров), его несохранённый черновик не теряется: он принудительно сохраняется тем же путём сохранения, что и Enter, и редактор закрывается; после этого строки обновляются данными прогона как раньше.

**Blocked by:** 01 — Инлайн-правка текста реплики (tracer-боллет).

**Status:** ready-for-human

- [x] Состояние «диаризация выполняется» читается из существующего общего стора прогона диаризации (тот же источник, что у панели спикеров) — нового состояния не вводить.
- [x] TDD: компонентный тест — при активной диаризации карандаш не показывается и редактор не открывается; при `isRecording` — тоже (регрессия гейта из 01).
- [x] TDD: компонентный тест — старт прогона при открытом редакторе сохраняет черновик один раз (команда вызывается ровно раз) и закрывает редактор.
- [ ] Ручная проверка: во время диаризации кнопки панели спикеров и правка текста заблокированы согласованно.
