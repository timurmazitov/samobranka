# 05: Ручная верификация в Tauri-приложении и отчёт

Type: task

**What to build:** Функция правки текста транскрипта проверена целиком в настоящем десктоп-приложении, а результат задокументирован так, как требует руководство агента: что именно проверялось, на какой платформе, что осталось непроверенным. Никакого приватного содержимого встреч в отчёте — только синтетические/красные данные.

**Blocked by:** 01, 02, 03, 04.

**Status:** ready-for-human

- [ ] Прогон `pnpm run tauri:dev` из `frontend/` (с выполненной первичной настройкой sidecar из документации по сборке).
- [ ] Сценарий: открыть сохранённую встречу → исправить реплику (Enter) → правка видна сразу → перезапуск приложения → правка на месте.
- [ ] Проверить, что копирование и экспорт транскрипта отдают исправленный текст.
- [ ] Проверить, что поиск по транскрипту находит место по исправленному слову.
- [ ] Проверить пересоздание саммари после правки (кнопка подсказки) — новое саммари построено из исправленного текста.
- [ ] Проверить недоступность правки во время записи (живая панель и страница) и во время диаризации.
- [ ] Проверить, что правка не ломает воспроизведение аудио по строке и атрибуцию спикера.
- [ ] Итоговый отчёт в комментариях к этому тикету: платформа, список проверенных пунктов, наблюдения, явно перечисленное непроверенное.
