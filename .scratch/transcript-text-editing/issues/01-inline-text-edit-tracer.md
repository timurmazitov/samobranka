# 01: Инлайн-правка текста реплики (tracer-боллет)

Type: task

**What to build:** На странице сохранённой встречи, когда запись не идёт, пользователь наводит курсор на текст реплики транскрипта — появляется иконка-карандаш. Клик по иконке превращает текст реплики в редактируемое поле с авто-высотой, в котором показан исходный (неочищенный от слов-паразитов) текст. Пользователь печатает исправление и нажимает Enter — строка на экране мгновенно показывает новый текст, а после перезапуска приложения правка остаётся. Потеря фокуса сохраняет так же. Тайминги и спикер реплики не меняются: воспроизведение по строке и атрибуция работают как раньше.

Полный вертикальный срез: новая Tauri-команда правки текста одной строки (UPDATE только колонки текста в транзакте с bump времени изменения встречи; нормализация пробельных символов — переносы из вставки схлопываются в одиночные пробелы, trim по краям), оптимистичный in-place апдейт строки в хуке пагинации транскриптов по образцу правки спикера, UI-правка в компоненте строки виртуализированного представления по образцу компонента правки заголовка.

**Blocked by:** None (can start immediately).

**Status:** resolved
