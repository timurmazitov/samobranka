# 04: Подсказка «Пересоздать саммари» после правки

Type: task

**What to build:** Саммари встречи генерируется из текста реплик, читаемого из базы, поэтому после правки текста уже созданное саммари устаревает. После успешного сохранения правки, если у встречи уже есть готовое саммари, пользователь видит ненавязчивую подсказку (тост) с кнопкой, которая запускает существующее действие «пересоздать саммари». Автоматического пересоздания не происходит — это тяжёлую операцию запускает только пользователь. Если саммари у встречи нет, подсказка не показывается.

**Blocked by:** 01 — Инлайн-правка текста реплики (tracer-боллет).

**Status:** resolved

- [x] Подсказка появляется после успешного сохранения правки только при наличии готового саммари у встречи.
- [x] Кнопка в подсказке вызывает существующее действие пересоздания саммари; новый путь генерации не появляется.
- [x] Подсказка не дублируется на каждую правку подряд (несколько сохранённых правок подряд не плодят одинаковые тосты — достаточно одного актуального).
- [ ] Проверка сценария: исправить текст → пересоздать саммари кнопкой → в новом саммари отражён исправленный текст.
