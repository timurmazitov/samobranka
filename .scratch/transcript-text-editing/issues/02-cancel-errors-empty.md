# 02: Отмена правки, ошибки сохранения и «нельзя пусто»

Type: task

**What to build:** Пользователь, открывший правку текста реплики, может передумать: Escape возвращает исходный текст без какого-либо обращения к бэкенду. Пустая или состоящая только из пробелов правка не сохраняется: бэкенд отвергает такое значение, на экране появляется понятный тост об ошибке, строка остаётся с прежним текстом. Если сохранение упало по любой другой причине (команда вернула ошибку), строка на экране откатывается к значению, которое было до правки, — пользователь никогда не видит текст, которого нет в базе.

**Blocked by:** 01 — Инлайн-правка текста реплики (tracer-боллет).

**Status:** resolved

- [x] TDD: тест репозитория — пустая строка и строка из одних пробелов отвергаются с ошибкой, значение в базе не меняется.
- [x] TDD: тест хука — при ошибке команды строка в состоянии возвращается к прежнему тексту.
- [x] TDD: компонентный тест — Escape закрывает редактор, возвращает исходный текст и не вызывает команду; пустое значение не приводит к успешному сохранению и показывает тост об ошибке.
- [x] Текст тоста user-friendly и не содержит содержимого встречи (требования приватности из руководства агента).
