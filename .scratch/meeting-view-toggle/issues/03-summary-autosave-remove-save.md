# 03: Автосохранение саммари и удаление кнопки Save

**What to build:** Правки конспекта сохраняются автоматически: при потере фокуса редактором BlockNote (только при несохранённых правках) и детерминированно — в обработчике смены вкладки перед самим переключением (через ref-API редактора, до размонтирования панели). Кнопка Save и индикатор «грязного» состояния удаляются с панели саммари; Copy/Export по-прежнему берут текущее состояние редактора. Диалогов подтверждения при переключении нет.

## Comments

Реализация (коммит `4a09a3b`; ревью-фиксы `3333dff`, `42d864e`, `ac0cce2`):

- **Blur-автосейв** (`SummaryPanel.tsx`): `onBlur` на скролл-контейнере редактора (bubbling focusout из contenteditable BlockNote), dirty-guarded вызов `saveSummary()` через ref-API; ошибка — тост, успех — тихо.
- **Детерминированный сейв перед переключением** (`page-content.tsx`): общий `requestTabChange(tab)` используется и таб-стрипом, и навигацией из «Найти и заменить» (ревью-фикс `42d864e` — раньше find-nav шёл в обход гарда): уходим с конспекта при грязном редакторе ⇒ ref захватывается синхронно до любых setState, сейв await-ится, переключение после resolve; при ошибке — тост `toasts.meetingData.changesSaveFailed` и вкладка не меняется (редактор и правки живы). Диалогов нет.
- **Дедупликация конкурентных сейвов** (`BlockNoteSummaryView.tsx`, ревью-фикс `3333dff`): `handleSave` возвращает in-flight промис повторным вызовам вместо параллельного дубля (клик по вкладке = blur + onTabChange одновременно); счётчик версий правок сохраняет «грязность» правок, сделанных во время сейва.
