# 06: Единая панель кнопок и возврат поля контекста вниз панели транскрипта

**What to build:** Переключатели «Конспект / Транскрипт» и кнопки активного режима делят одну общую панель-строку (сплит-вью владеет строкой: переключатели слева, слот-выход справа; панели регистрируют свою строку кнопок через `PanelToolbarOutletContext` / `usePanelToolbar`, без провайдера рисуют шапку локально). Набор видимых кнопок автоматически следует режиму за счёт размонтирования неактивной панели. Поле дополнительного контекста саммаризации возвращается вниз панели транскрипта (под список реплик) с прежним условием показа (`!isRecording && convertedSegments.length > 0`) и отсутствует в режиме конспекта; панель саммари получает значение без обработчика ввода (`onPromptChange`/`isRecording` удалены, `customPrompt` остаётся — Generate/Regenerate потребляют его). Попутно чинится регрессия высоты: пустой wrapper неактивной вкладки Radix с атрибутом `hidden` перебивается классом `flex` (zero-specificity `[hidden]` в preflight) и забирал 50% высоты — на `TabsContent` добавлен `[&[hidden]]:hidden`.

**Supersedes:** 04 (размещение поля рядом с Generate отменено — пользователь трактует контекст как относящийся к транскрипту)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Переключатель и кнопки активного режима рендерятся в одной панели-строке; набор кнопок меняется при смене режима
- [ ] Поле контекста видно внизу панели транскрипта (под списком реплик) и отсутствует на панели конспекта; условия показа прежние
- [ ] Введённый текст доезжает до Generate (пропсовая связь через страницу встречи)
- [ ] Активная панель занимает всю высоту области контента в обоих режимах (регрессия 50% высоты закрыта)
- [ ] Тесты: шов 3 (панель-строка), ассерт `[&[hidden]]:hidden` в шве 2, адаптация prompt-тестов
