# 02: Глобальное запоминание выбора вкладки

**What to build:** Ручной выбор «Конспект / Транспект» запоминается глобально (один на все встречи, localStorage) и восстанавливается при открытии любой встречи как начальное состояние. Существующая логика авто-переключения сохранена: автопереход на конспект при появлении саммари (один раз на встречу, если пользователь не выбирал вкладку руками), ручной выбор для конкретной встречи побеждает автоматику, навигация из «Найти и заменить» по-прежнему переключает вкладку на панель с совпадением.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Ручной выбор вкладки пишется в новый ключ localStorage и восстанавливается при следующем открытии любой встречи
- [ ] Авто-переход на конспект при завершении генерации саммари работает, если вкладку не выбирали руками для этой встречи
- [ ] Ручной выбор для конкретной встречи не перебивается ни запомненным глобальным режимом, ни автопереходом
- [ ] Навигация по совпадениям из «Найти и заменить» переключает вкладку на нужную панель
- [ ] Page-level тест на существующем харнессе страницы встречи проходит (persistence чтение/запись, автопереход с гардами)
