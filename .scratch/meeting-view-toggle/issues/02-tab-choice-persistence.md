# 02: Глобальное запоминание выбора вкладки

**What to build:** Ручной выбор «Конспект / Транспект» запоминается глобально (один на все встречи, localStorage) и восстанавливается при открытии любой встречи как начальное состояние. Существующая логика авто-переключения сохранена: автопереход на конспект при появлении саммари (один раз на встречу, если пользователь не выбирал вкладку руками), ручной выбор для конкретной встречи побеждает автоматику, навигация из «Найти и заменить» по-прежнему переключает вкладку на панель с совпадением.

**Blocked by:** 01

**Status:** resolved

- [x] Ручной выбор вкладки пишется в новый ключ localStorage и восстанавливается при следующем открытии любой встречи
- [x] Авто-переход на конспект при завершении генерации саммари работает, если вкладку не выбирали руками для этой встречи
- [x] Ручной выбор для конкретной встречи не перебивается ни запомненным глобальным режимом, ни автопереходом
- [x] Навигация по совпадениям из «Найти и заменить» переключает вкладку на нужную панель
- [x] Page-level тест на существующем харнессе страницы встречи проходит (persistence чтение/запись, автопереход с гардами)

## Comments

Реализация (коммит `cdcd917`; ревью-фиксы `5877ffc`, `42d864e`):

- **Хранилище** (`src/lib/meeting-details-preferences.ts`, новый): guarded read/write по образцу `summary-language-preferences.ts`; ключ `samobranka.meetingDetails.activeTab`; валидация значения (`'summary'|'transcript'`, мусор → null). Старый ключ пропорции игнорируется, миграции нет.
- **Страница** (`page-content.tsx`): инициализатор `useState` — `readMeetingDetailsActiveTab() ?? 'summary'` (дефолт «Конспект», story 4); запись в `onTabChange` — только после того, как переключение реально произошло (сразу или после успешного сейва саммари — порядок исправлен ревью-фиксом `42d864e`, неудачный сейв не запоминает несостоявшийся выбор).
- **Авто-переход**: после ревью-фикса `5877ffc` срабатывает только на переходе `processing|summarizing|regenerating → completed`, наблюдаемом в этой сессии просмотра (один раз на встречу, гард ручного выбора сохранён). До фикса эффект срабатывал и при открытии встречи с уже готовым саммари, что обесценивало запомненный режим (конфликт story 5/story 6, найден spec-ревью).
- **Навигация из «Найти и заменить»** переключает вкладку, но не пишет ни в storage, ни в ручной гард (поведение закреплено ревью-фиксом).
- **Тесты**: новый page-level сьют `meeting-details-tab-persistence.test.tsx` (9 тестов: запись/чтение, дефолт `'summary'`, восстановление на другой встрече, автопереход с гардами, ручной выбор побеждает, открытие с готовым саммари + запомненный `'transcript'` ⇒ остаётся транскрипт; Map-backed шим `window.localStorage` с save/restore). Соседние сьюты зелёные (mode-exclusivity 8, summary-hint 17, find-replace ×2, split-view 5 и др.).
- **Проверки**: bun пофайлово — 22 сьюта, 216 pass / 0 fail (финальное состояние после ревью-фиксов); `tsc --noEmit` — только baseline-ошибка.
