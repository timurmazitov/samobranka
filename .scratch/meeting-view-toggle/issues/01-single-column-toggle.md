# 01: Единая колонка с переключателем «Конспект / Транскрипт» на всех экранах

**What to build:** Переработка сплит-вью страницы встречи: переключатель «Конспект / Транскрипт» (две взаимоисключающие кнопки с иконкой и текстом на базе существующего Radix Tabs) виден на любом размере окна, активна ровно одна панель — транскрипт или саммари, неактивная панель размонтируется. Drag-разделитель, пропорция панелей и её сохранение в localStorage удалены. Содержимое панелей и их проп-интерфейсы не меняются.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] На десктопе и на узком экране видна одна и та же раскладка: одна текстовая колонка и две кнопки переключения «Конспект» / «Транскрипт» (иконка + текст, существующие i18n-строки); активная кнопка подсвечена
- [x] При переключении неактивная панель размонтируется (а не скрывается); прокрутка при открытии панели сброшена вверх
- [x] Drag-разделителя, логики ресайза и CSS-переменной ширины панели транскрипта больше нет; старый ключ пропорции в localStorage игнорируется
- [x] Панели транскрипта и саммари, их тулбары и пустые состояния работают без изменений
- [x] Компонентный тест сплит-вью с фейковыми панелями проходит: обе кнопки видны независимо от вьюпорта, переключение размонтирует неактивную панель
